## ADDED Requirements

### Requirement: Midnight Indigo Theme Mode
The application SHALL support a "Midnight Indigo" theme mode in settings alongside Dark, Light, and System modes, utilizing deep navy backgrounds, cobalt/cyan accents, and glassmorphic card borders.

#### Scenario: Switching to Midnight Indigo theme
- **WHEN** the user selects "Midnight Indigo" in the appearance settings
- **THEN** the app persists the preference and renders background gradients and surfaces with the Midnight Indigo palette

#### Scenario: Contrast and readability
- **WHEN** Midnight Indigo theme is active
- **THEN** primary text displays high-contrast white and secondary text renders soft blue-gray
